One row per source-claim pair. 6 parallel branches (B1–B6) + a deepening/
verification pass (DV). 120 distinct search queries.

Status key: `confirmed` — source directly supports the claim · `corrected` —
supports a narrower version · `contested` — credible sources disagree ·
`demoted` — source exists, quality weak for this claim · `rejected` — should not
appear in findings.
